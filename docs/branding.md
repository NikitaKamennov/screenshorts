# ScreenShooter Pro: название и совместимость

С 21 ноября 2026 года название продукта — **ScreenShooter Pro**: screen + shooter,
инструмент для захвата экрана. Бинарники новых сборок — `ScreenShooterPro.exe`
в Windows и `ScreenShooterPro` в Linux. Отображаемые названия, справка, документация,
скрипты, будущие имена комплектов и материалы YouTube приведены к этому имени.

Основной раздел интерфейса называется **«Библиотека»**. Прежняя метафора полки,
притяжательные заголовки и декоративная иллюстрация полки убраны. Вместо них —
знак захвата с перекрестием, компактная навигация, нейтральные подписи, спокойные
поверхности и акцент на действии захвата. Цвет акцента и сохранённая тема остаются
пользовательскими настройками. Обновление не добавляет внешних ресурсов интерфейса.

## Что сохраняется ради прежних данных

- Каталог исходников и Go-модуль `skrinpolka`, профиль `%LOCALAPPDATA%\Skrinpolka`
  в Windows и `skrinpolka` в пользовательском каталоге Linux.
- Схемы `skrinpolka-*`, технические схемы/маркеры `screenshorts-*`, ключи JSON,
  идентификатор единственного экземпляра и системные идентификаторы приложения.
- Корзина `.screenshorts-trash` и её квитанции, существующие настройки и OCR.
- Чтение снимков с префиксами `ScreenShorts Pro`, `Скринполка` и ранними hex-ID.

Это внутренние контракты совместимости, а не названия в интерфейсе. Существующие
PNG, JSON и пользовательские каталоги автоматически не переименовываются.
Новые снимки получают имена `ScreenShooter Pro ГГГГ-ММ-ДД ЧЧ-ММ-СС.png`.
Оба имени EXE учитываются при защите сборщика от работающего приложения.
Идентификатор Windows-установщика сохранён для будущего обновления; установщик
по этому поручению не собирается.

## Объём текущей работы

Подготовлены исходники оформления и переименования для Windows/Linux. По запросу
владельца собран только локальный Windows EXE с уже подготовленными компонентами:
`.local-data/build/windows-bundle-shelf/ScreenShooterPro/ScreenShooterPro.exe`.
Новые portable/установщик и Linux-комплект не собираются. Изменения Linux в этом
срезе прочитаны вручную; прежний успешный Linux build относится к прежнему названию.

Позже 21 ноября владелец дал отдельный сигнал на **Windows portable ZIP** для
YouTube. Архив комплектуется из этого EXE и готовых runtime; установщик и Linux
по этому сигналу не собираются. Ссылка Яндекс Диска добавляется владельцем после
загрузки; описание направляет пользователей Linux на GitHub с инструкциями.

Запуск приложения, OCR/моделей, тесты, go vet, проверки синтаксиса, браузерные и
smoke-проверки не выполняются. Новое оформление требует ручной приёмки владельцем.
