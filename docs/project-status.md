# Статус проекта и проверок

Состояние документации на **18 ноября 2026 года**. Здесь разделены
реализованные функции, полученные сборки и фактические проверки.
Наличие кода или успешная компиляция не подтверждают работу на каждой ОС.

## Что уже реализовано

Go/Wails-приложение, четыре режима захвата, настройки комбинаций, трей,
редактор, темы и переставляемые панели; PNG + JSON, комментарии,
OCR rus/eng, фоновая обработка новых сохранений и текстовый поиск.
Полка имеет миниатюры/таблицу, сортировки, группы, предпросмотр,
выбор, копирование, ZIP и восстанавливаемую корзину.

Подготовлен локальный CPU-worker удаления фона с прозрачным PNG,
undo/redo и отменой. Его функциональная приёмка **не подтверждена**.
Полные комплекты включают движок и модель; это не результат проверки качества.

## Что фактически проверялось

| Область | Имеющиеся результаты | Что остаётся |
| --- | --- | --- |
| Linux, ранняя версия | Пользователь вручную подтвердил захват, OCR, смену комбинации и настройку панели | Повторить актуальную версию, полку и весь цикл; матрица X11/Wayland не закрыта |
| Windows 10, захват | Пройдены Win32-проверки и dev-проба области, сохранения и повторов после Escape | Все режимы, длительная работа, мониторы и смешанный DPI |
| Windows 10, OCR и поиск | После исправления запускался комплектный Tesseract rus/eng, повтор из карточки и поиск по результату | Чистая машина, очереди/ошибки/отмена и остальные конфигурации |
| Windows 10, полка | Проверка на 72 искусственных записях; пользователь затем подтвердил работу полки | Linux и дальнейшая регрессия |
| Windows-комплект | Полная папка, portable ZIP и установщик скомпилированы | Установка, обновление, удаление, чистая ОС без runtime; полный аудит уведомлений |
| Linux-комплект | Полная сборка и повтор с --offline выполнены; получены папка, .run, .tar.gz, спецификация и SHA | Приложение из этого комплекта, OCR и модель не запускались; проверка на чистых Ubuntu/Mint впереди |
| Удаление фона | Исходники, lock/manifest, Linux-окружение и комплектные компоненты подготовлены | Качество, скорость, память, прозрачность, отмена и изоляция на обеих ОС |

Результаты относятся к указанным версиям и не заменяют проверку новой сборки.
Подробности полки и её ограничений — в [описании полки](shelf.md).

## Статус поставки

Windows release-конфиг использует версию 0.1.0-dev и not-accepted.
Linux — 0.1.0-linux-portable и manual-pending.
Это текущие метки сборщиков, а не обещание стабильного выпуска.

Цель Linux-комплекта: Ubuntu 24.04 / Mint 22.x x86_64, glibc 2.39+.
Другие дистрибутивы, ARM, musl и 32 bit не заявлены.
Windows x64 проверялась на Windows 10; отдельная полная приёмка Windows 11
и всех вариантов установки не зафиксирована.

Windows-комплект сохраняет незавершённый аудит условий и уведомлений
WebView2, app-local CRT и DLL Tesseract. Точный перечень —
[windows-notices.md](windows-notices.md). Публикация исходников с MIT
не означает готовности стороннего runtime к распространению.

## Что запланировано

- Подключение старых папок и восстанавливаемый SQLite/FTS-индекс.
- Семантический поиск по OCR и комментариям через небольшую локальную модель.
- Дальнейшие фотоинструменты и доводка платформенных сценариев.
- Полная приёмка автономных комплектов и сценариев обновления.

Сейчас поиск использует текст и подстроки; группировка похожего содержимого
сравнивает общие слова. Визуальные описания изображений не генерируются.
[Дальнейшие задачи](roadmap.md).

## Как фиксировать новую проверку

Запиши версию исходников/сборки, SHA файла, ОС и оболочку, способ запуска,
CPU/RAM, дисплеи/DPI, короткие шаги и результат. Используй искусственные снимки
и отдельный --data-root. Для Windows есть [таблица приёмки](windows-acceptance.md),
для Linux — [перечень сценариев комплекта](linux-portable.md#ручная-приёмка).
