# Дальнейшее развитие

Текущая реализация и результаты проверок — в [статусе проекта](project-status.md).
Перечисленные ниже возможности ещё не входят в готовые функции приложения.
Порядок может меняться; даты выпуска не обещаются.

## Ближайшие задачи

- Пройти полную проверку автономных Windows/Linux-комплектов на чистых ОС.
- Проверить установку, обновление и удаление Windows-версии.
- Завершить аудит уведомлений сторонних компонентов Windows-runtime.
- Проверить удаление фона: качество маски, прозрачный PNG, отмену, undo/redo,
  ресурсные ограничения и изоляцию на обеих платформах.
- Расширить матрицу мониторов/DPI, X11/Wayland, порталов, трея и горячих клавиш.

## Библиотека и поиск

- Подключать несколько папок без перемещения исходных файлов.
- Добавить восстанавливаемый SQLite/FTS-индекс поверх переносимых PNG + JSON.
- Обрабатывать внешнее добавление/изменение файлов и восстанавливать индекс.
- Добавить семантический поиск по OCR и комментариям через небольшую
  локальную текстовую модель с явным runtime и лицензией.

Сейчас работают поиск по тексту и группировка по общим словам. Будущая модель
не должна подменять комментарий пользователя или индексировать скрытые пиксели.
Автоматические визуальные описания не входят в текущую реализацию.

## Редактор и надёжность

Дальнейшие фотоинструменты, ручная коррекция маски удаления фона, обработка
очень больших библиотек, восстановление после сбоев и доводка обновлений.
Точные пользовательские сценарии добавляются в документацию вместе с реализацией.

Принципы проекта сохраняются: локальная обработка, одна тяжёлая задача,
ограничения ресурсов, отмена, отдельная изоляция Windows/Linux и переносимые
метаданные. План не является подтверждением готовности перечисленных функций.
