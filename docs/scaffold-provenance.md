# Происхождение каркаса

Дата: 16 ноября 2026 года. Источник опыта и зависимостей — соседний проект
Zvukbook («Звуккниг»), собственный код которого опубликован под MIT.

## Что перенесено и адаптировано

- Набор Go/Wails-зависимостей из `desktop/go.mod` и `desktop/go.sum`: новый
  модуль называется `skrinpolka`, версия Wails сохранена v2.15.0.
- Подход к desktop-окну: Go-методы для нативных диалогов, Wails bindings,
  отдельный каталог данных и настройки WebView2 на Windows.
- Отображение ошибки запуска через Windows MessageBox в GUI-сборке.
- Раздельные сборки Windows/Linux, явный каталог локальных данных, сохранение
  результата независимо от будущей нейросетевой обработки.
- Четыре MIT-файла Windows-защиты из `desktop/internal/winhost/`: адаптированы
  в `internal/sandboxwin/` для отдельного OCR-worker. Используются AppContainer,
  ACL и Job Object; журналы со стандартным выводом worker заменены на NUL,
  диагностическая запись ACL на диск убрана. Код исходного проекта не менялся.
- MIT-уведомление Звукбука сохранено в [licenses/zvukbook/LICENSE](../licenses/zvukbook/LICENSE).

## Что создано для ScreenShooter Pro

Новые Go-ядро, PNG-библиотека, формат sidecar, интерфейс, справка,
платформенные/ML-контракты, сборочные скрипты, спецификация и план.
Python-backend Звукбука не нужен этому каркасу. Защиты подключены через
собственный адаптер OCR; прежняя приёмка Звукбука не подтверждает корректность
новых путей, ACL, зависимостей Tesseract и жизненного цикла. Linux использует
свой systemd/cgroup v2/bubblewrap адаптер, не Windows-код.

## Границы переноса

Из Звукбука не переносились история Git, книги, SQLite, MP3, .env, журналы,
готовые сборки, окружения Python, CUDA, модели, runtime и прочие личные данные.
Новая программа не обращается к путям библиотеки Звукбука и может развиваться
в собственной копии каталога без соседнего проекта.
