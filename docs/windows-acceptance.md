# Windows: ручная приёмка самостоятельного комплекта

В ограниченной проверке на Windows 10 Pro 19045 подтверждены захват области
900×400, сохранение и повтор после Escape. Комплектный OCR rus/eng, повтор
из карточки и поиск по результату также проверялись. Это не полная приёмка
всех сценариев ниже. [Сводный статус](project-status.md).

Скомпилированные EXE, ZIP и установщик не подтверждают работу на каждой ОС.
Для новой сборки нужна отдельная проверка; отсутствующая конфигурация
остаётся непроверенной.

Для каждого прогона запиши версию/сборку Windows, CPU/RAM, мониторы и масштаб,
версию приложения, SHA установщика/ZIP и способ запуска. Статусы: «пройден»,
«ошибка», «не проверен»; отсутствие нужной конфигурации не засчитывается.
Не включай личные снимки, настройки, библиотеки и логи в исходники.

## Подготовка

1. Возьми полный комплект из [инструкции сборки](windows-quick-build.md).
   Распакуй **всю** папку вне репозитория на локальный NTFS; в пути желательно
   проверить пробелы и кириллицу. Не запускай EXE прямо внутри ZIP.
2. Для portable-пробы передай новый абсолютный `--data-root`, например
   `--data-root "D:\ScreenShooter Pro проба\данные"`. Библиотека должна содержать
   только вымышленные изображения и текст. Настройки рабочей копии не нужны.
3. Для доказательства автономности нужна отдельная чистая Windows x64 без Go,
   Python, Tesseract, отдельно установленного WebView2 и инструментов сборки.
   Отключи сеть до первого запуска и оставь отключённой для OCR и удаления фона.
   Не удаляй общие компоненты с рабочей Windows ради проверки.

## Сценарии и ожидаемый результат

| Сценарий | Ожидаемое поведение | Результат |
| --- | --- | --- |
| Первый запуск без сети | Открывается окно; нет запроса скачать runtime, указать Python/модель или выбрать профиль | Не проверен |
| Tray и закрытие | После появления рабочего трея закрытие возвращаемо; без трея окно остаётся доступным; «Выйти» завершает приложение | Не проверен |
| Повторный запуск | Открывается прежнее окно, не появляется второй независимый экземпляр | Не проверен |
| Четыре комбинации | Область, экран с редактором, тихий экран и тихая область; конфликт объясняется, прежние клавиши сохраняются при отказе | Не проверен |
| Отмена выделения | Escape/правая кнопка, смена фокуса/мониторов и сон отменяют выбор без сохранения | Не проверен |
| DPI/мониторы | 100/125/150/200%, смешанный масштаб, монитор левее/выше основного; границы снимка совпадают с выделением | Не проверен |
| Топология тихой области | После смены расположения/масштаба или старой настройки без topology приложение просит выбрать область заново | Не проверен |
| Слишком большой рабочий стол | Лимит 16 млн пикселей объясняется; доступен выбор меньшей области | Не проверен |
| Редактор | Стрелки, фигуры, скрытие, crop, undo/redo, панели, размер и тема работают и сохраняют настройки | Не проверен |
| Enter | В комментарии/OCR переводит строку; после захвата сохраняет итог и возвращает прежнее окно при разрешении ОС | Не проверен |
| PNG + JSON | Оба файла рядом; совпавшее имя получает суффикс; прежние записи не перезаписываются | Не проверен |
| Отказ записи | Редактор и комментарий остаются доступны; сохранение не объявляется успешным | Не проверен |
| Тихие снимки | Нет редактора/переключения фокуса/уведомления; ошибка видна при следующем открытии библиотеки | Не проверен |
| OCR rus/eng без сети | Новый сохранённый снимок обрабатывается комплектным движком; поиск находит слова и комментарий | Не проверен |
| Пустой OCR / ошибка | Необязательный комментарий предлагается только после успешного результата без текста; очередь и ошибки отличаются | Не проверен |
| Сохранность текста | Ручной комментарий и исправленный OCR не затираются результатом модели | Не проверен |
| Только итоговые пиксели | Скрытый/обрезанный вымышленный текст отсутствует в OCR и производных данных | Не проверен |
| Удаление фона без сети | Прозрачность и PNG; undo возвращает фон; очередь общая с OCR; ошибка сохраняет черновик | Не проверен |
| Отмена/лимиты worker | Задача и её дерево завершаются; нет продолжения после отмены и обхода защиты при отказе | Не проверен |
| Изоляция | Подтверждён отказ доступа к посторонним данным/сети; собственные runtime доступны только для чтения | Не проверен |
| Перенос полной папки | После нового переноса всё работает с комплектным runtime без путей к репозиторию/кэшу/системному Python | Не проверен |
| Повторный запуск и сон | Настройки/пары сохранены; нет зависшего выделения, клавиш или тяжёлой задачи | Не проверен |

Для дисплеев фиксируй масштаб и расположение каждого монитора. Изоляцию и лимиты
нужно проверять отдельно от успешного OCR: обычный результат распознавания
не доказывает отсутствие доступа к другим данным.

## Установщик

Используй отдельного обычного пользователя/тестовую Windows. Установка,
обновление и удаление программы — отдельные ручные действия, не часть сборки.

| Сценарий | Ожидаемое поведение | Результат |
| --- | --- | --- |
| Установка без сети | Без UAC и установки общих зависимостей; ярлык «Пуск», рабочий стол только по выбору | Не проверен |
| Первый запуск из ярлыка | Тот же полный офлайн-сценарий; настройки и библиотека отдельно от программы | Не проверен |
| Работающее приложение | Обновление/удаление требуют полного выхода, не принудительно завершают приложение | Не проверен |
| Обновление | Настройки/PNG/JSON сохранены; неизменённые устаревшие программные файлы убраны по прежним SHA | Не проверен |
| Чужие файлы | Неизвестные файлы сохраняются; непустой чужой каталог и junction/symlink отвергаются до установки | Не проверен |
| Удаление | Удалены только файлы установщика и ярлыки; библиотека и настройки сохранены | Не проверен |
| Повторная установка | Сохранённая библиотека доступна; runtime полностью комплектный | Не проверен |

При ошибке укажи шаг, ожидаемое и фактическое поведение. Для приложения полезен
текст видимой ошибки; для сборки — сообщение скрипта и его код завершения.
Не отмечай весь блок пройденным по одному успешному сценарию.
