# Уведомления Windows-комплекта

Полный сборщик сохраняет уведомления Go и FlatBuffers вместе с runtime.
Аудит поставки пока не завершён. Чтение архивов и build info не заменяет
функциональную приёмку на ОС.

Реальная сборка `build-windows.ps1 -Release` завершилась успешно: получены
полная папка, ZIP и установщик. Из EXE go1.25.3 собраны 18 модулей, всего
36 файлов уведомлений Go/toolchain; runtime receipt перечисляет 12 обязательных
уведомлений и три оставшихся пункта аудита. SHA всех файлов включены в manifest
комплекта. Фактические проверки приложения отражены
в [актуальном статусе](project-status.md); приёмка цикла
установщика остаётся открытой.

## Go

После компиляции `notices.ps1` читает метаданные **собранного EXE** командой
`go version -m`: бинарник при этом не исполняется. Только перечисленные там
модули сопоставляются с `go.sum`; их LICENSE/COPYING/NOTICE/PATENTS и другие
именованные уведомления копируются с сохранением структуры. Замены модулей
и неизвестные lock-записи останавливают комплектование, а не пропускаются.

Также сохраняются LICENSE/PATENTS фактически использованного Go toolchain
и уведомления его `src/vendor`. Системный каталог компилятора используется
только для чтения этих общедоступных лицензионных файлов; он не изменяется.
`licenses/go/manifest.json` связывает версию toolchain, модули/Go sum и
SHA файлов с хешем EXE. Абсолютные пути машины сборщика туда не включаются.

## Python и модель

- CPython: полный `runtime/python/LICENSE.txt` из проверенного embed ZIP.
- ONNX Runtime: LICENSE и ThirdPartyNotices.txt внутри пакета `onnxruntime/`.
- NumPy/Pillow/packaging/protobuf: полные `.dist-info` с вложенными лицензиями
  из закреплённых wheels. Эти подкаталоги не вырезаются при упаковке.
- FlatBuffers: выбранный wheel не содержит LICENSE. Файл версии 25.12.19
  взят из [upstream](https://github.com/google/flatbuffers/blob/v25.12.19/LICENSE),
  сохранён в `licenses/flatbuffers` вместе с URL/версией/размером/SHA.
  Несовпадение с версией wheel или хешем останавливает сборку.
- U²-NetP/rembg: сохранены прежние исходные уведомления и manifest модели.

`licenses/runtime-notices.json` перечисляет обязательные уведомления с SHA
и оставшиеся вопросы; наличие этого receipt не означает закрытый аудит.

## Что остаётся

1. Microsoft WebView2: полный текст условий поставки и доступные офлайн
   уведомления всех встроенных сторонних компонентов. Полный CAB сохранён;
   `show_third_party_software_licenses.bat` требует запуска WebView2.
   Для поставки нужны готовые офлайн-уведомления из первичного источника.
2. Microsoft CRT: текст применимых условий распространения app-local DLL,
   связанный с выбранным VSIX. Сам VSIX не содержит отдельной лицензии.
3. Tesseract Windows: сохранена Apache-лицензия движка и его документация,
   но все DLL дистрибутива имеют собственные условия. Требуется собрать
   точный перечень/уведомления и установить состав соответствующих исходников,
   не выдавая лицензию Tesseract за лицензию всех DLL.

Комплект сохраняет статус `not-accepted`; публикация и коммиты автоматически
не выполняются. Вопросы выше не требуют установки зависимостей пользователем.
Сеть разрешена при подготовке сборки; обработка изображений в готовом
приложении должна оставаться полностью локальной.
