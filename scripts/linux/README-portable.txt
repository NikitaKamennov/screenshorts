ScreenShooter Pro — Linux x86_64

Запуск папки: дважды щёлкни ScreenShooterPro или выполни ./ScreenShooterPro.
Самораспаковывающийся файл .run: разреши выполнение в свойствах и запусти.
Перед запуском пересобранной версии выйди из старой через меню трея.
При первом запуске .run проверяет SHA-256 и распаковывает комплект в
$XDG_CACHE_HOME/skrinpolka/portable/ (обычно ~/.cache/skrinpolka/portable).
Дальнейшие запуски используют эту копию. FUSE и установщик не требуются.

Go, Python, Tesseract, GTK/WebKitGTK отдельно устанавливать не нужно:
компоненты входят в папку. Для удаления фона включён CPU-runtime и U²-NetP.
Первый выпуск предназначен для Ubuntu 24.04 / Mint 22 x86_64 (glibc 2.39+).
Нужна обычная графическая сессия, системный D-Bus, systemd user manager,
cgroup v2 и разрешённые user namespaces. Это возможности ОС, не runtime
приложения. Без разрешённой изоляции OCR/удаление фона не запускаются.
Ни root, ни отключение защиты ОС не предусмотрены.

X11: обычный и тихий захват. Wayland: системные порталы, возможен запрос
разрешения; тихие режимы в текущей версии недоступны. Трей зависит от оболочки.
Программа и комплект собраны; функциональная приёмка на чистых ОС впереди.

Данные отдельно: ~/.local/share/skrinpolka/ (или $XDG_DATA_HOME/skrinpolka).
Папку снимков можно выбрать в настройках. Для отдельной пробы:
./ScreenShooterPro --data-root /абсолютный/путь/к/новой-библиотеке
Удаление папки программы/кэша .run не удаляет библиотеку.

Сохраняй PNG вместе с соседним JSON для переноса комментариев и OCR.
Справка: ? в шапке / F1. Полная инструкция — docs/user-guide.md.

Внутри licenses/, THIRD-PARTY.md и runtime-manifest.json — уведомления,
версии, происхождение и хеши компонентов. Собственный код MIT, зависимости
и модель имеют отдельные лицензии. Статус приёмки указан в release-manifest.json.
